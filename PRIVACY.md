# Privacy Policy — SellX Uploader

_Last updated: 2026-10-05_

"SellX Uploader" is a private build tool used only by the owner of this repository
(Mohamed Nasser) to copy SellX POS Local installer files from GitHub Actions into the
owner's own Google Drive.

* **Data accessed:** only files that this tool itself uploads (Google Drive scope
  `drive.file`). It cannot see, read or change any other file in Google Drive.
* **Data collected:** none. No personal data is collected, stored, shared or sold.
* **Data shared:** none. Uploaded files stay in the owner's Google Drive.
* **Users:** the tool is not offered to the public; only the owner signs in.

Revoke access at any time: https://myaccount.google.com/permissions

Contact: open an issue at https://github.com/Mohamed1320Nasser/sellx-pos-releases/issues
